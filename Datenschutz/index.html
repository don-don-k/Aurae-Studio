Diese Verarbeitung erfolgt durch den Hostinganbieter. Wir betreiben keinen eigenen Webserver und führen über die Website keine eigene Kundendatenbank.

Weitere Informationen zur Verarbeitung personenbezogener Daten finden Sie in den Datenschutzhinweisen von GitHub .

5. Google Maps und Routenplanung

Im Bereich „Standort“ wird eine Karte nicht automatisch geladen. Erst wenn Sie auf „Karte anzeigen“ klicken, wird eine Verbindung zu Google Maps hergestellt und die Karte eingebunden. Dabei können insbesondere Ihre IP-Adresse und technische Verbindungsdaten an Google übermittelt werden.

Über den Button „Route planen“ können Sie Google Maps öffnen. Dabei wird eine externe Website aufgerufen; auch hierbei können Daten an Google übertragen werden. Für die weitere Verarbeitung durch Google gelten die Datenschutzbestimmungen des jeweiligen Anbieters.

Google Maps wird über einen externen Dienst eingebunden. Die konkrete datenschutzrechtliche Grundlage für das Laden der Karte und die dafür erforderliche Information beziehungsweise Einwilligung muss entsprechend der tatsächlichen technischen Umsetzung sichergestellt werden.

6. Terminanfragen über Instagram

Über das Terminformular können Sie Ihren Namen, die gewünschte Behandlung, einen Wunschtermin und optional eine Anmerkung eingeben. Die Angaben werden im Browser Ihres Geräts zu einem Nachrichtentext verarbeitet. Eine Übermittlung an einen von uns betriebenen Server oder eine Speicherung in einer eigenen Kundendatenbank findet durch dieses Formular nicht statt.

Wenn Sie die Instagram-Option wählen, versucht die Website, den vorbereiteten Text in die Zwischenablage Ihres Geräts zu kopieren. Anschließend werden Sie zu Instagram weitergeleitet. Dort können Sie den Text in eine Direktnachricht einfügen und selbst versenden. Die Übermittlung des Nachrichtentextes an Instagram erfolgt durch das Versenden der Nachricht.

Die Nutzung der Zwischenablage erfolgt auf Ihrem Gerät. Je nach Browser und Geräteeinstellungen kann das Kopieren eingeschränkt sein. In diesem Fall müssen Sie die Nachricht selbst eingeben.

Wenn Sie uns über Instagram kontaktieren, verarbeiten wir die von Ihnen übermittelten Angaben zur Bearbeitung Ihrer Anfrage und zur Terminabstimmung. Für die Verarbeitung durch Instagram gelten zusätzlich die Datenschutzbestimmungen des Dienstanbieters Meta.

Das Terminformular übermittelt die eingegebenen Daten nicht an eine eigene Kundendatenbank. Die Daten können jedoch vorübergehend im Browser und in der Zwischenablage Ihres Geräts vorhanden sein. Wenn Sie eine Direktnachricht an uns senden, können die darin enthaltenen Angaben anschließend in Instagram und in unserem dortigen Nachrichtenverlauf gespeichert werden. Diese Nachrichten werden von uns nur so lange aufbewahrt, wie dies für die Bearbeitung und Dokumentation der Terminanfrage erforderlich ist oder gesetzliche Pflichten dies verlangen.
